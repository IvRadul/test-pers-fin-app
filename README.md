# Personal Finance App (Test Version)

Пробная версия приложения для учёта личных доходов и расходов.  
Создано в учебных/экспериментальных целях.

## 🚀 Возможности

- Добавление доходных и расходных операций
- Просмотр списка транзакций по категориям и за определённый период

## 🛠 Технологии

- Язык программирования: Python
- База данных: SQLite
